# When Does Rendered Synthetic Handwriting Help? (reproduction package)

Reproduction package for the paper *When Does Rendered Synthetic Handwriting Help? A Replicated Study of Fine-Tuning
Pretrained HTR Models in Four Settings*.

**Status:** in preparation. The repository stays private until its first release (1.0.0 at the first submission).

Planned contents: environment (Docker), configurations of the synthetic pools, training and evaluation scripts, the
statistical analysis (Welch intervals, Holm correction, hierarchical bootstrap) and the captured results behind every table
and figure. Per-line predictions on CatK12HW-actions are not included while the corpus is private.
